# LearnBuddy 接入悟码AI

本适配包含一个可导入的教师技能文件夹，以及一个本地只读 MCP 连接器。连接器直接读取悟码AI SQLite数据库，不需要额外模型调用。

## 1. 升级并启动悟码AI

在PowerShell中执行：

```powershell
Set-Location D:\AI_Coding\wuma_ai_v1_3_16
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\upgrade_from_v1_3_15.ps1"
python -m streamlit run app.py
```

## 2. 添加连接器

1. 打开LearnBuddy左侧“专家·技能·连接器”，进入“连接器”。
2. 选择“自定义连接器”，复制 `mcp_config.example.json` 的内容。
3. 若项目路径不是 `D:\AI_Coding\wuma_ai_v1_3_16`，将配置中的Python、脚本和数据库路径替换为实际绝对路径。
4. 保存后测试连接。应看到4个工具：班级概况、教师待办、学生诊断、学生进展。

示例配置使用已安装依赖的虚拟环境Python：`D:\AI_Coding\.venv\Scripts\python.exe`。如果你的虚拟环境位置不同，只改 `command` 的绝对路径，不要在 `args` 中增加 `-3.12`。

连接器只读，不会修改成绩、教师复核或学生反馈；也不会输出学生代码、回答原文、隐藏测试输入输出和隐藏教学重点。

## 3. 导入教师技能

1. 在“技能”页面选择“添加技能”→“导入技能”。
2. 在文件夹选择器中进入 `D:\AI_Coding\wuma_ai_v1_3_16\learnbuddy\wuma-ai-teacher`，点击“选择文件夹”。
3. 文件夹选择器只显示子文件夹，因此进入后看似空白是正常现象；不要继续寻找ZIP或单独选择 `SKILL.md`。
4. 导入成功后，在新任务输入框上方确认已启用“悟码AI教师助手”，并确认“wuma-ai”连接器状态正常。

## 4. 赛事展示前检查

1. 在悟码AI网页的`.env`中确认智能服务可用；它负责网页中的出题、评价与报告生成，不是LearnBuddy接口。
2. 在LearnBuddy新建演示任务。赛事要求体现为最终操作与结果均在LearnBuddy中呈现，平台底部显示哪个可用模型不影响悟码AI Skill与MCP的接入方式。
3. 确认输入框上方已启用“悟码AI教师助手”，连接器列表中的“wuma-ai”状态正常。
4. 使用下方短指令演示一次当前待办和一次学生进展。当前待办为空时应直接说明“暂无当前待办”，不要再把历史提交称为未处理。

LearnBuddy、悟码AI网页和连接器的职责如下：

| 层级 | 职责 |
| --- | --- |
| LearnBuddy | 赛事指定交互载体，承载对话、技能与连接器 |
| LearnBuddy当前模型 | 由平台配置，理解教师请求并组织最终自然语言回答 |
| 悟码AI教师技能 | 规定查询流程、输出口径和隐私边界 |
| wuma-ai MCP连接器 | 只读查询悟码AI SQLite数据库并返回结构化证据 |
| 悟码AI网页侧腾讯混元 | 生成答辩题、评价学生回答和生成诊断报告 |

## 5. 演示指令


```text

```

```text

```

如果连接失败，先确认悟码AI数据库已经由升级脚本复制到 `data\wuma_ai.db`，再确认配置中的Python、脚本和数据库路径均存在。
