# LearnBuddy接入悟码AI

LearnBuddy组织教师对话，Skill规定查询和解释口径，MCP连接器读取授权范围内的结构化教学数据；教师在悟码AI网页保存复核结论。

## 个人连接

1. 启动完整本地app.py，使用教师入口登录。
2. 在“班级与学生管理 → LearnBuddy－个人只读连接”生成并下载个人配置。已有有效连接无需重复生成；新令牌会撤销旧令牌。
3. 按LearnBuddy当前连接器界面导入个人配置。配置含令牌，只在本人本机使用，不上传源码、聊天或参赛附件。
4. 导入本包learnbuddy/wuma-ai-teacher文件夹或对应Skill ZIP并启用。技能版本为2026-10-09-v2；本轮连接器隐私修复未增加工具或参数。

管理员使用独立账号，不生成教学连接。缺少令牌或跨教师班级的请求会被拒绝。连接器以SQLite只读模式打开数据；不会创建业务记录或保存复核结论。

## 四个只读工具

| 工具 | 参数 | 用途 |
| --- | --- | --- |
| wuma_teacher_overview | assignment_id可选 | 权限内概况 |
| wuma_pending_teacher_tasks | assignment_id可选，limit可选1—50 | 当前待办 |
| wuma_student_diagnosis | submission_id必填 | 单次精简诊断 |
| wuma_student_progress | student_id必填，保持学号原字符串 | 学生提交进展 |

先查待办；空队列不能用已处理历史替代。只有当前工具结果才能说明当前状态。教师提出重答要求不等于学生已经理解；分数不等于课程成绩。

网站与连接器须核对相同“数据源标识”、教师权限、实验、提交及读取时间。网页选择的班级不会自动成为MCP参数。MCP是本机stdio进程，不能自动读取Streamlit Cloud的SQLite。公开只读网页与本机演练数据库分别管理。

连接器仅返回精简状态，不返回学生代码、回答原文、隐藏参考要点或隐藏测试输入输出；原文在教师网页按权限核查。

## 查询验收

启用连接后，分别查询概况、当前待办、工具返回的实际提交编号及教师有权访问的实际学号。保留工具参数、数据快照及对应网页状态。不要使用示例编号冒充本次记录。

本轮本地stdio四工具、只读哈希、权限及私有字段检查已通过；这不是一次新的LearnBuddy平台交互。docs/learnbuddy_history保存2026-10-10真实平台历史截图，详见该目录的来源说明。
