### 实验描述

直接复制：

```text
给定n个整数，请使用数组保存这些数据，并通过循环求出其中的最大值。程序需要正确处理全负数、只有一个元素、最大值重复出现等合法输入，只输出最大值。
本实验同时考查代码运行结果、解题思路以及对初始化、循环边界和相近需求修改的理解。
```

### 输入格式

```text
第一行输入一个整数n，表示元素个数。
接下来输入n个整数a0、a1、……、a(n-1)，整数之间用空格或换行分隔。
每次运行只处理一组数据。
```

### 输出格式

```text
输出一个整数，表示这n个整数中的最大值，最后换行。
不要输出“最大值是”等提示文字，不要输出调试信息。
```

### 数据范围与说明

```text
1 ≤ n ≤ 100。
-1000000000 ≤ ai ≤ 1000000000，所有数据均为整数。
输入保证包含完整的n个整数；数值可以为负数、零或正数，可以重复。
n=0、n>100以及输入不完整不属于正式判题范围。可以讨论对这些情况的健壮性处理，但不能把它们直接视为本题正确性缺陷。
```

### 实验要求（每行一条）

```text
使用C++编写完整程序，包含int main。
使用容量不少于100的数组保存输入的n个整数。
使用循环遍历有效元素，输出最大值，不使用排序代替遍历比较。
最大值变量从实际数组元素初始化，正确处理全负数和单个元素。
填写解题思路，说明初始化依据、循环起止位置和至少一个合法边界案例。
实验报告为选做，可补充算法设计、测试情况和复杂度分析。
```

### 隐藏教学重点（每行一条，学生不可见）

```text
结合变量maximum解释为什么从a[0]初始化，而不是从0初始化；使用全负数作为反例。
结合i=1和i<n解释循环范围；说明初始化已处理第一个元素，以及n=1时不需要比较。
说明遍历到第i个元素后，maximum是已处理前缀中的最大值；能跟踪一次具体执行过程。
核查学生能否分析全负数、重复最大值、最大值在首尾位置和n=100等合法情况。
修改为求最小值时，同时说明变量含义、比较方向和从a[0]初始化的依据。
分析遍历的时间复杂度以及除数组外的辅助空间；区别数组存储与辅助空间。
n=0或超过100仅作为可选健壮性扩展，必须先明确这些输入不在本题范围内。
```

## 6. 核查答案的依据

| 核查主题 | 正确理解 | 典型误解 |
| --- | --- | --- |
| 初始化 | a[0]是已存在的候选最大值；全负数也有效。 | 最大值总是非负数，所以可以从0开始。 |
| 循环起点 | 初始化已纳入a[0]，从1开始比较剩余元素。 | 从1开始意味着漏掉首元素。 |
| 循环终点 | 最后有效下标是n-1，条件应为i<n。 | 用i<=n多比较一次也没关系。 |
| 单个元素 | maximum=a[0]，比较循环不执行，直接输出该值。 | 必须再读入一个元素才能输出。 |
| 相等元素 | 求最大值时不更新也不影响数值；统计出现次数时需额外处理相等情况。 | 必须每次遇到相等值都更新，否则结果错误。 |
| 最小值修改 | 初值仍为a[0]，比较方向改为<，输出最小值变量。 | 只改变量名，或初值改为0。 |
| 输入范围 | n=0是范围外扩展，不能据此判本题代码错误。 | 把范围外输入当正式隐藏测试扣正确性分。 |

对于动态生成的题目，应按照实际问题核查回答，不要求学生背诵固定文字。AI分数可以有波动，验收重点是是否引用真实回答、指出具体缺口，并允许教师复核。

## 7. 教师复核和反馈用语

### 认可正确回答

处理结论：认可AI诊断。

教师复核意见：

```text
已核查代码与逐题回答。学生能解释maximum从a[0]初始化的依据，说明循环有效范围，并正确分析全负数和单个元素。最小值修改方案与原代码一致，同意本次诊断。
```

此选项会把教师确认理解度同步为AI答辩理解度。不要强行填写一个与AI不同的分数。

### 要求理解不足的学生重新答辩

处理结论：要求学生重新答辩。

教师复核意见：

```text
代码通过测试，但回答仍混淆“代码运行正确”和“理解实现依据”。请用全负数案例解释为何不能从0初始化，并说明求最小值时需要怎样修改比较语句。重新答辩时请结合自己的maximum变量和循环范围回答。
```

学生应从任务中心进入重答，新报告显示第2轮；教师能比较前后证据。重答不应覆盖原问答与原复核记录。

### 回复学生学习指导反馈

处理状态：已回复。

教师回复：

```text
可以把maximum理解为“当前已读过元素中的最大值”。先令它等于a[0]，再依次与后面的元素比较；遇到更大的数才更新。请用-7、-2、-9、-5手动跟踪一次：初值-7，读到-2时更新为-2，之后保持-2。这样就能理解为什么不能从0初始化。
```
