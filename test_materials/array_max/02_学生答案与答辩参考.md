### 解题思路

直接复制：

```text
先读入元素个数n，并把n个整数存入数组a。因为题目保证n至少为1，所以可以用a[0]初始化maximum，确保初值来自输入，而不是假定最大值为非负数。
随后从下标1开始，循环到下标n-1；当a[i]比maximum更大时更新maximum。每处理完一个元素，maximum都是已经处理过的元素中的最大值，所以循环结束后得到整个数组的最大值。
全负数时这种初始化仍然正确；n=1时比较循环不执行，直接输出a[0]；重复最大值不会改变结果。两次遍历的时间复杂度为O(n)，除保存数据的数组外，辅助空间为O(1)。最后只输出最大值并换行。
```

## 2. AI答辩答案

当前版本会结合实际代码动态生成3道题，依次考查逻辑、概念与边界、分析与修改。下面是常见问题的对应答案；先看网页实际问题，再选择相关部分作答。不要把整份答案库一次性粘贴到每道题。

### 逻辑题：为什么用a[0]初始化maximum？

```text
a[0]是输入中的实际元素，题目保证n≥1，因此它可以作为最初的候选最大值。不能把初值随意设成0：例如-7、-2、-9、-5全部为负数时，它们都不会大于0，程序就会错误输出并不存在于数组中的0。用a[0]初始化后，遇到-2时会把maximum从-7更新为-2，最终正确输出-2。
```

### 逻辑题：为什么从i=1开始，而不是i=0？

```text
因为maximum=a[0]已经把第一个元素纳入比较结果了，所以从下标1开始处理剩余元素，没有漏掉首元素。如果从0开始也能求出相同的最大值，但会额外进行一次a[0]与自身的比较。当前写法比较n-1次。
```

### 逻辑题：跟踪3、8、2、6、1时maximum的变化

```text
maximum初始为a[0]=3。i=1时a[1]=8，大于3，更新为8；之后的2、6、1都不大于8，因此不再更新，最后输出8。每次比较后，maximum都是已经处理过的前缀中的最大值。
```

### 边界题：n=1时会发生什么？

```text
读入一个元素后，maximum等于a[0]。比较循环从i=1开始，1<n不成立，循环不执行，直接输出这个唯一元素。无论这个元素是正数、零还是负数都能正确处理。
```

### 边界题：循环条件为什么是i<n？

```text
长度为n时有效下标是0到n-1，所以i<n恰好遍历剩余有效元素。若改为i<=n，就会访问a[n]；当n=100时这是数组越界，当n<100时也访问了不属于有效输入且未初始化的元素，不能参与求最大值。
```

### 边界题：重复最大值或全相等会出错吗？

```text
不会。当前任务只输出最大数值，所以遇到相等元素时不更新maximum也不会改变结果。例如7、7、7、7，初值已经是7，后面的比较均不更新，最终仍输出7。如果新任务要求统计最大值出现次数，就需要额外处理相等情况。
```

### 修改题：改为求最小值

```text
把变量含义改为minimum，仍用a[0]初始化，因为最小值也应该从实际元素开始。循环范围保持i=1到n-1；把条件a[i]>maximum改成a[i]<minimum，满足条件就更新minimum，最后输出minimum。不能只改变量名，也不能改成从0初始化，否则全正数时可能错误输出0。
```

关键代码：

```cpp
int minimum = a[0];
for (int i = 1; i < n; ++i) {
    if (a[i] < minimum) {
        minimum = a[i];
    }
}
cout << minimum << '\n';
```

### 修改题：同时求最大值和最大值出现次数

```text
从a[0]初始化maximum，计数count初始化为1。从i=1开始比较：遇到更大的数时更新maximum并把count重置为1；遇到等于maximum的数时count加1；遇到更小的数时都不变。最后输出maximum和count。重置计数很重要，因为旧的较小最大值出现次数不能计入新的最大值。
```

关键代码：

```cpp
int maximum = a[0];
int count = 1;
for (int i = 1; i < n; ++i) {
    if (a[i] > maximum) {
        maximum = a[i];
        count = 1;
    } else if (a[i] == maximum) {
        ++count;
    }
}
cout << maximum << ' ' << count << '\n';
```

这个片段仅用于回答修改题；原实验正式提交仍只输出最大值。

### 分析题：复杂度和是否需要排序

```text
读入和求最大值各遍历一次，因此总时间为O(n)，比较阶段进行n-1次比较。固定数组保存100个int，除数组外的辅助空间为O(1)。如果数组按n分配，则数组存储空间为O(n)。求最大值不需要排序；一般比较排序会增加到O(n log n)时间，还会改变元素原有顺序，单次遍历更直接。
```

### 可选扩展题：n=0或n超过100怎么办？

```text
这两种情况不在本题正式范围内。如果把它们作为健壮性扩展，n=0时没有元素，也就不能访问a[0]来求最大值；n超过100时固定数组不足，不能继续读入到越界位置。当前程序检查n范围后提前返回。若任务允许任意长度，需另行规定空集合的输出，并改用合适的动态存储或流式处理。
```

### 追问：如何解释“已处理前缀的最大值”？

```text
初始化后，已处理部分只有a[0]，maximum显然是它的最大值。每次加入a[i]时，如果它更大就更新，否则保留旧值，因此maximum仍然是加入新元素后这部分数据的最大值。循环结束时已处理全部元素，所以maximum就是整个数组的最大值。
```
