### 实验描述

```text
给定n个整数，请使用数组保存数据，并使用选择排序将它们按非递减顺序排列。
选择排序每轮从尚未排序的部分找出最小元素，将它放到该部分的首位，然后继续处理剩余元素。要求自己实现查找和交换过程，不使用sort、stable_sort或其他排序算法代替选择排序。
程序最后输出排序后的全部整数。重复元素必须完整保留，负数和零也应正确处理。
```

```text

接下来输入n个整数，整数之间用空格或换行分隔。
每次运行只处理一组数据。
```

```text

非递减顺序指前面的数不大于后面的数，允许相邻元素相等。
不要输出输入提示、说明文字或每轮排序的中间结果。
```

### 隐藏教学重点（每行一条，学生不可见）

```text
结合实际变量说明minIndex保存最小元素的下标，不能把它与最小元素的数值混淆。
解释为什么每轮将minIndex初始化为i，内层从j=i+1开始，条件为j<n。
解释外层循环i<n-1：完成前n-1个位置后，最后一个元素自然就位；n=1时无需排序。
说明开始第i轮时，a[0..i-1]是已排好且不大于未排序元素的前缀；本轮选择最小元素放到a[i]。
解释为什么先完成本轮最小元素查找再交换，以及为什么交换需要临时变量或等效安全操作。
结合全负数、重复值、n=2、逆序和最大长度100检查下标与元素数量；重复元素不能删除。
比较标准选择排序的最好、平均和最坏时间复杂度均为O(n²)，辅助空间O(1)；参考实现比较n(n-1)/2次，实际交换至多n-1次。
经典直接交换的选择排序一般不稳定；可用带标签的(2,A)、(2,B)、(1,C)解释，但本题不要求稳定性，不能据此扣正确性分。
核查修改为降序时比较方向和每轮目标怎样改变；如问统计交换次数，应区分实际交换与元素比较。
输入输出测试只能检查数值结果，不能证明使用了选择排序；必须结合代码和答辩核查算法过程。
```

## 6. 教师核查要点与常见错误

按变量含义和实际行为核查，不要求学生使用与参考代码相同的变量名。等价写法也应认可：例如正确地使用swap交换，或外层写成i<n、最后一轮没有候选元素可比较，仍可得到正确结果；后一种写法只是多处理一次已经确定的位置，不能直接判为排序错误。

| 核查主题 | 参考要点 | 需要关注的错误 |
| --- | --- | --- |
| minIndex的含义 | 它是下标，a[minIndex]才是候选最小值。 | 把a[j]赋给minIndex，随后拿元素数值当下标访问数组。 |
| 每轮初始化 | 从i开始，因为前缀已经排好，本轮只处理后缀。 | 每轮都初始化为0，破坏已经排好的部分。 |
| 内层范围 | j从i+1到n-1，检查所有剩余候选元素。 | j<n-1遗漏最后一个元素，或j<=n访问无效位置。 |
| 交换时机 | 完成本轮最小值查找后交换a[i]与a[minIndex]。 | 在查找过程中不断交换却仍声称符合要求的标准选择排序过程。 |
| 交换赋值 | 保存旧a[i]，再把最小元素放到a[i]，最后将旧值放回原最小值位置。 | 连续写a[i]=a[minIndex]、a[minIndex]=a[i]，导致旧a[i]丢失。 |
| 重复元素 | 数值相等不必更新minIndex，输出数量保持n个。 | 把排序错误地当成去重。 |
| n=1与n=2 | 单元素直接输出；双元素进行一轮比较，必要时交换。 | 外层写成i<n-2，双元素逆序时根本不排序。 |
| 比较与交换次数 | 标准参考实现比较n(n-1)/2次；只在下标不同才交换，至多n-1次。 | 混淆比较次数与实际交换次数，认为每次比较都要交换。 |
| 已排序输入 | 参考实现仍检查剩余元素，时间仍为O(n²)，实际交换为0次。 | 因为无需交换就把时间复杂度认定为O(n)。 |
| 稳定性 | 直接交换的选择排序一般不稳定；本题无需保证稳定性。 | 用“相等时不更新minIndex”推断整个算法一定稳定。 |
| 降序修改 | 每轮选最大元素，比较方向改为>，候选下标仍从i初始化。 | 只改变量名称，未改变比较方向。 |

带标签的稳定性示例仅用于教师理解：[(2,A),(2,B),(1,C)]首轮交换后变成[(1,C),(2,B),(2,A)]，两个数值2的相对顺序被改变。正式题目只输入整数，不增加标签输入要求。

## 8. 教师参考答案（用于发布前自检）

完整代码如下，也可以打开 [teacher_reference.cpp](D:/AI_Coding/wuma_ai_v1_4/test_materials/selection_sort/teacher_reference.cpp) 复制。粘贴到“教师参考答案（仅教师可见）”，用于检查题面与测试数据的一致性。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    if (!(cin >> n) || n < 1 || n > 100) {
        return 0;
    }

    int a[100];
    for (int i = 0; i < n; ++i) {
        if (!(cin >> a[i])) {
            return 0;
        }
    }

    for (int i = 0; i < n - 1; ++i) {
        int minIndex = i;
        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[minIndex]) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            int temp = a[i];
            a[i] = a[minIndex];
            a[minIndex] = temp;
        }
    }

    for (int i = 0; i < n; ++i) {
        if (i > 0) {
            cout << ' ';
        }
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```
